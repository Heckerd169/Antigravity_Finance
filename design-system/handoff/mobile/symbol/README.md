**Warum die obere Reihe wichtiger ist als die untere.** Ein Symbol, das vergrößert
überzeugt, kann bei 60 px verschwinden. Variante D ist deshalb bewusst mitgezeichnet: Sie
zeigt den Zustand **vor** diesem Sprint — den Screenshot, den iOS ohne eigenes Symbol
nimmt — und bei 60 px ist darauf nichts zu erkennen.
